How the model works

The simulation uses the far-field diffraction model with an 80 nm slit width and a screen 1 metre away. Diffracting through a finite slit creates a sinc-squared envelope. When the paths are indistinguishable, the added amplitudes produce interference inside that envelope. An ideal path detector makes the paths fully distinguishable, so their probabilities add.

The model samples the predicted horizontal position for each hit and uses the vertical space to spread impacts for display. Probabilities are normalized over the visible screen. Changing the setup starts a new sample.
