How it works

The 1D linear shallow-water model uses a fixed, submerged bed. It represents small waves over long wavelengths. Pool entry is a prescribed incoming wave, and the open end approximates outgoing flow.

Breaking, dry-beach run-up, and sideways effects are outside the model. Use it for concept comparisons before engineering design.
