# North Carolina beach forecasts

The North Carolina region contains 46 named beaches and coastal locations, grouped north to south. The default is Nags Head; the former generic Outer Banks preset has been removed. Indian Beach and North Topsail Beach are separate choices.

Coordinates below are approximate representative oceanfront points, not survey positions, access locations, buoy stations, or individual surf breaks. Open-Meteo selects an offshore model cell; nearby beaches can share that cell and return similar forecasts.

## Saved locations

Named saved beaches restore the matching region/location controls. Existing saves labelled Outer Banks, NC migrate to Nags Head instead of continuing to display a generic location. Custom coordinate saves retain their coordinates.
